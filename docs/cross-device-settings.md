# 跨设备配置同步

## 新电脑如何恢复

打开服务器网站，在顶部「登录后恢复配置」或「配置 → 账号与同步」使用同一个 Always API 账号登录。生图网站建立独立登录会话；仅登录 Always API 后台不会自动登录生图网站。

登录后自动读取个人渠道密钥、模型和工具绑定、跨境模型及抠图凭据、WebDAV、提示词来源、语言和主题；同时读取已发布团队类目、品牌、默认出图要求和附件。个人代理地址保留在各自电脑，不参与同步。

修改个人配置后自动保存，首次修改也会保存。另一个设备重新回到页面或下一次版本检查时应用新版；有本机未保存修改时显示差异，不静默覆盖。团队发布、刷新与个人自动保存独立，不会清掉个人未保存内容。

## 旧电脑首次迁移

未曾上传到服务器的浏览器数据，必须在保存这些内容的旧电脑完成一次迁移：

1. 在旧电脑打开服务器网站并登录原账号，进入「配置 → 账号与同步」。请使用原服务器网址，不要切到 localhost。
2. 点击「一次迁移旧电脑配置」，检查本机候选与服务器的差异。候选在读取服务器前已按账号保存在本机，刷新页面不会丢失。
3. 确认旧电脑的个人配置才是所需版本时，点击「确认迁移个人配置」。这一步会替换该账号服务器上的个人配置，密钥不会共享给其他成员。
4. 团队管理员点击「上传附件并保存团队迁移草稿」。先上传类目示例图、Logo和字体，再保存；缺文件会明确提示补传，不能静默忽略。
5. 前往「跨境类目规则」查看团队草稿、品牌和最终要求，校验后发布。新版设备才会使用这套团队规则。

不要在没有旧配置的新电脑把空白候选迁移覆盖到服务器。新电脑只需登录恢复，无须执行上述迁移。

## 团队规则与附件

管理员身份由服务器账号ID授权，浏览器PIN和模型API key不授予管理权限。普通成员可读取团队规则，不能上传团队附件、修改草稿或发布。

原文件地毯／地垫／桌垫的三个大类、十个子类可以纳入真实团队草稿。洞洞板、收纳筐若原版本没有对应示例，初始草稿保留为停用类目；补上示例后可启用，不编造示例图。

配置附件采用服务器引用，支持PNG/JPEG/WebP/GIF和TTF/OTF/WOFF/WOFF2，每个文件最多20MB。字体和品牌图无需在新电脑重新上传。私密配置与附件加密存储，不写入公开规则目录。

退出登录会清除当前浏览器中的渠道、WebDAV和抠图凭据。切换账号后不会带入上一账号的私密配置，旧请求也不会回写或继续使用过期凭据发送模型请求。

## 此次不迁移

历史任务、画布、商品实拍、生成图片与记录仍留在原浏览器；本次不是完整工作区同步。已有任务继续引用原规则和品牌版本，不因新版本发布被改写。

## 运维和验证

服务部署及管理员配置见 `config-vault/README.md`。前端/团队数据契约为 `web/src/types/settings-sync.ts`；旧 `/api/config-vault/config` 保留兼容且不能删除新版设置域。

真实双浏览器联调：从 `web/` 执行 `node tests/settings-sync.real.e2e.mjs`，使用独立本地服务、合成账号与配置，验证密钥隔离、附件、首次保存、冲突及退出清理，不调用真实模型。结果位于 `web/test-results/settings-sync-real/`。
