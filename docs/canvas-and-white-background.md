# 画布与商品白底图功能说明

本文介绍应用中的**无限画布**与**商品白底图**功能，便于用户快速上手、整理素材并完成图片处理。

## 功能范围

- **无限画布**：以节点和连线组织提示词、图片、视频、音频及生成配置，支持多画布保存、迭代和导出。
- **商品白底图**：将商品原图处理为纯白背景主图，并在生成后继续调整商品位置、角度、大小、透视和颜色。
- 两个功能可以互相配合：白底图结果可以送入画布继续创作，也可以保存到素材库复用。

## 无限画布

### 进入方式

- 打开顶部导航中的“画布”。
- 在画布库中新建画布，或打开已有画布。
- 画布地址为 `/canvas`；打开具体项目时使用 `/canvas/{画布 ID}`。

### 画布基础操作

- **平移**：拖动画布空白区域。
- **缩放**：使用鼠标滚轮或缩放滑杆；“重置视图”可恢复默认视图。
- **选择**：点击节点单选；按住 `Shift`、`Ctrl` 或 `Cmd` 可增删选择；按住 `Ctrl/Cmd` 拖动可框选。
- **复制与删除**：使用 `Ctrl/Cmd + C`、`Ctrl/Cmd + V` 复制和粘贴；使用 `Delete` 或 `Backspace` 删除选中节点或连线。
- **撤销与重做**：使用 `Ctrl/Cmd + Z` 撤销，使用 `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` 重做。
- **分组**：选中多个节点后点击“分组”，或使用 `Ctrl/Cmd + G`；取消分组使用 `Ctrl/Cmd + Shift + G`。
- **导入素材**：将图片或视频文件拖入画布，或从“我的素材”插入已保存内容。

按 `Esc` 可清除选择并关闭当前浮层。撤销与重做覆盖节点、连线、视口和画布背景模式等编辑操作。

### 节点类型与用途

#### 文本节点

用于记录想法、提示词、方案描述和 AI 生成的文本。

- 双击文本内容，或在工具栏选择“编辑文本”进行修改。
- 可以在编辑面板中让 AI 改写文本；编辑已有文本时会在右侧创建结果节点，原节点保留。
- 使用 `@` 可引用已连接的图片、文本、视频或音频，引用内容会作为上下文发送给模型。
- 从文本节点选择“生成图片”时，系统会创建并连接生图配置节点，再按配置生成图片。

#### 图片节点

用于存放上传图片、生成结果和参考图。

- 空图片节点生成时，结果写入当前节点。
- 已有内容的图片节点会作为参考图使用。
- 生成节点会记录提示词、生成类型、模型、尺寸、质量、数量和参考图等信息。
- 参考图已丢失时，重试会提示无法恢复，需重新添加参考图。

#### 视频和音频节点

视频节点支持本地上传和生成结果预览；音频节点可作为画布素材或生成参考。生成配置会读取上游节点中的提示词、图片、视频和音频，并将它们组合到请求中。

#### 配置节点与扩展节点

配置节点用于集中调整模型、尺寸、比例、质量和生成数量等参数。扩展节点由插件提供，可在画布中参与生成流程；具体字段以扩展节点自身说明为准。

#### 组节点

组节点用于将多个节点作为一个整体移动和引用。选中多个节点后创建分组，也可以先创建空组，再把节点拖入或拖出。

### 推荐工作流

1. 新建文本节点，写下创作目标和初始提示词。
2. 在文本编辑面板中让 AI 优化提示词，并保留原始版本用于对比。
3. 从合适的文本节点生成图片，按需要调整生图配置。
4. 将生成结果、参考图和补充说明整理到同一组中。
5. 继续迭代，完成后导出画布或导出选中的节点。

### 画布保存与导出

- 画布项目、节点、连线、视口和外观设置会单独保存。
- 可在画布库中重命名、打开、删除和导入画布。
- 可以导出当前画布，也可以只导出选中的节点。
- 图片、视频等较大的媒体文件会保存为本地素材引用；导入或迁移时应同时保留对应媒体文件。

## 商品白底图

### 进入方式

打开顶部导航中的“商品白底图”，或访问 `/image?mode=product-white`。

### 生成白底图

1. 点击“上传商品图片”，选择一张商品原图。
2. 选择处理方式：
   - **AI 白底优化**：使用当前配置的图片模型生成白底主图。
   - **已配置的抠图 API**：使用已配置的抠图服务提取商品主体；未配置时该选项不可用。
3. 选择输出尺寸：`800 × 800`、`1024 × 1024`、`1254 × 1254` 或 `1600 × 1600`。
4. 选择输出格式：JPG 或 PNG。
5. 点击“生成白底图”，等待结果出现在右侧预览区。

默认输出为纯白背景、96 DPI，文件大小上限为 2 MB。AI 处理结果仍应人工核对商品结构、颜色、纹理、配件数量和边缘是否自然。

### 编辑白底图

生成结果后，可以点击“编辑构图与颜色”进入调整面板。编辑稿会自动保存草稿，点击“保存调整”后生成新的白底处理记录，原版本仍会保留。

#### 构图调整

- **拖动商品**：直接在预览画布中拖动主体。
- **键盘微调**：聚焦预览画布后使用方向键移动；按住 `Shift` 可使用更大步长。
- **旋转**：输入角度，或快速左转/右转 90°。
- **等比缩放**：调整主体大小，保持宽高比例。
- **居中**：将商品主体放回画布中心。
- **适应画布**：自动缩放并放置商品，避免主体超出画布。
- **重置构图**：恢复默认旋转、缩放和位置。
- **主体透视**：开启后可拖动四个角点，调整主体的透视位置；不需要透视变形时保持关闭。

如果主体超出画布，页面会显示“超出部分将被裁切”提示，可点击“完整放入画布”自动修正。

#### 颜色调整

支持以下调整项，范围均为 `-100` 至 `100`：

- 色温（冷 / 暖）
- 色调（绿 / 洋红）
- 饱和度
- 亮度
- 对比度

点击“查看调色前”可以在保持构图不变的情况下对比原始颜色；“全部还原”会将颜色和构图恢复为默认值。

### 使用与导出

在“使用这张白底图”区域可以：

- **保存调整**：保存当前编辑结果并保留旧版本。
- **下载白底图**：按当前调整效果导出 JPG 或 PNG 文件。
- **送入画布**：创建一个新画布，并将当前白底图作为图片节点插入。
- **保存到素材库**：将结果作为图片素材保存，后续可从画布或其他图片工作流中复用。

下载和送入画布使用的是当前调整后的结果；如果只修改了草稿但尚未保存，执行这些操作时系统会先处理当前草稿。

## 数据与配置

- 画布、白底处理记录、编辑草稿和素材默认保存在当前浏览器的本地工作区。
- 图片模型、抠图服务和其他工具需要在“配置”中设置对应渠道后才能使用。
- 更换浏览器或设备前，应先导出工作区或按项目提供的迁移方式备份；仅保存页面地址不会带走本地图片和编辑记录。
- API Key 属于个人配置，导出配置文件前请妥善保管，避免公开分享。

## 常见问题

### 生成按钮不可用

请先上传商品图片，并检查是否已完成图片模型配置。使用抠图 API 时，还需要配置可用的抠图服务地址。

### 结果边缘或商品结构不正确

优先保留原图并重新生成，或改用已配置的抠图 API。AI 白底优化可能会改变细节，不能替代人工检查。

### 调整后出现裁切

点击“完整放入画布”或缩小主体；也可以重新执行“适应画布”。

### 画布中的图片无法预览

检查对应素材是否仍在当前浏览器工作区中。若只导入了画布数据而没有导入媒体文件，需要重新上传图片或恢复完整工作区备份。

### 修改没有保留

等待草稿保存完成后再关闭页面，并使用“保存调整”明确提交当前版本。浏览器清理站点数据会删除本地画布、素材和编辑记录。
