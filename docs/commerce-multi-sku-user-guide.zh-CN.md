# 跨境生图：多 SKU 使用说明

本文说明如何在跨境生图中一次创建多个 SKU，并为每个 SKU 单独绑定类目规则、变体和材质/背面实拍。

## 一、开始前准备

准备以下资料：

- 商品 Excel。批量导入时，工作表名称优先使用“商品导入”；如果没有这个名称，系统读取第一个工作表。
- 商品主图。每个 SKU 建议准备 1–6 张，至少有一张能清楚识别商品主体的图片。
- 如果要生成材质、背面、包边或侧面画面，另行准备对应部位的真实拍摄图。正面白底图不能替代背面或材质实拍。
- 确认已经登录并完成配置同步。规则目录或模型配置仍在读取时，“新建任务”会保持不可用。

## 二、批量创建多 SKU 任务

1. 打开“跨境生图”，点击“新建任务”。
2. 在任务名称、平台和品牌中选择本批任务的公共设置。
3. 选择“Excel 批量导入”。
4. 上传商品 Excel；如有商品图片，也可以上传“商品图片 ZIP”。
5. 选择目标语言，检查生成配置（图片尺寸、格式、营销图、Logo、水印和交付方式）。
6. 点击“创建任务”。创建完成后进入任务详情页，左侧会列出本批的所有 SKU。

### Excel 字段

下列三个表头必填，名称需要完全一致：

| 表头 | 用途 |
| --- | --- |
| `SKU 编号` | 每个商品的唯一编号，同一批不能重复 |
| `商品类型(必填)` | 商品类型；没有单独填写类目时也会作为默认类目 |
| `产品名称(必填)` | 商品名称 |

常用可选表头如下：

| 表头 | 用途 |
| --- | --- |
| `品牌名称` | SKU 自带的品牌名称 |
| `产品类目` | 初始内部类目；创建后仍可在 SKU 详情中调整大类和子类 |
| `目标受众` | 场景和文案的受众信息 |
| `产品描述/卖点` | 商品描述或卖点 |
| `材质描述` / `产品材质` | 材质事实 |
| `使用方式` / `使用说明` | 使用和安装信息 |
| `产品尺寸` | 尺寸或尺寸列表 |
| `英文类目路径` | 展示用的英文类目路径，不改变内部类目规则 |
| `商品主图地址(多个用逗号分隔)` | 商品主图 URL，系统会尝试读取并保存 |
| `尺码图片地址` | 尺寸图 URL |

未识别的列会保存在商品扩展字段中，不会因为多出列而丢弃整行。

每批最多导入 20 个 SKU，SKU 编号不能重复。超过 20 个请拆成多个任务。

### 图片 ZIP 的目录格式

推荐将图片按 SKU 文件夹组织：

```text
商品资料/
  商品导入.xlsx        （可选；ZIP 内只能有一个 .xlsx）
  SKU-001/
    01.jpg
    02.jpg
    size.jpg
  SKU-002/
    01.png
    02.png
```

系统按文件夹名匹配 `SKU 编号`：

- `01.jpg` 至 `06.jpg` 会作为商品主图；也支持直接使用 `1.jpg` 至 `6.jpg`。
- 文件名以 `size.` 开头的图片会作为尺寸图。
- ZIP 外面可以再套一层目录。
- ZIP 中没有 Excel 时，仍需在左侧单独上传 Excel；ZIP 中有多个 Excel 时，必须单独选择要导入的 Excel。
- 图片 URL 会在 ZIP 图片之后补齐，最多保留 6 张主图。

如果 SKU 没有可读取的主图，系统会把它标记为缺图并阻止该 SKU 开始生成。

## 三、创建后逐个设置 SKU

多 SKU 任务共享任务级的平台、品牌、语言和输出设置，但以下内容按 SKU 独立保存：

- 大类和细分类目；
- 类目要求、示例图和生成方案；
- 商品事实（颜色、尺寸、材质、安装方式等）；
- 细节实拍及其变体归属；
- 方案数量、变体范围、提示词补充和人工审核状态；
- 白底图、无文字图、营销图及合规结果。

在任务详情左侧点击 SKU，按以下顺序处理：

### 1. 选择类目

在“类目作图方案与产品事实”中先选“商品大类”，再选“商品细分类目”。页面会显示最终生效的必须/建议规则和对应示例图。

子类会继承大类硬性要求。类目要求优先于补充提示词，补充设置不能取消类目强制要求。更换类目会清除该 SKU 当前版本中受影响的场景、营销图、审核和合规结果，需要重新生成。

### 2. 核对商品事实

如果方案要求颜色、尺寸、厚度、耐热温度、孔径或配件数量等参数，在“产品事实”中填写真实数据，并勾选“我已根据实物或检测数据核对以上参数”。不要用模型推测或未经验证的宣传词替代事实。

### 3. 上传细节实拍

在“SKU 细节实拍素材”中：

1. 点击“上传实拍”，上传正面纹理、背面、边缘、侧面或配件照片；也可以从“复用已有商品实拍”中选择已经上传的商品图。
2. 给每张图片勾选用途：正面纹理、背面、边缘、侧面、配件或其他。一张图可以勾选多个用途。
3. 在“素材变体”中填写颜色/尺寸等变体名称；留空表示当前商品。
4. 只有明确勾选“所有变体通用”的素材，才会跨变体复用。
5. 图片需要替换时点击“替换”；不再使用时点击“移除”。

背面和材质方案只会读取当前方案绑定的细节实拍，不会把正面白底图或类目示例图当成背面依据。缺少对应实拍时，请补图或关闭该方案，不能用白底图代替。

## 四、设置方案和多 SKU 变体

在“需求方案”中，每项方案可以单独：

- 勾选启用/停用；
- 设置数量（通常 0–4 张）；
- 选择变体范围；
- 对细节方案选择真实拍摄部位、绑定图片和主参考图；
- 选择“实拍保真优化”或“实拍原图排版”。

### 变体范围

| 选项 | 生成方式 | 使用条件 |
| --- | --- | --- |
| 每 SKU | 每个 SKU 生成一组 | 默认选项 |
| 每颜色 | 按颜色/花色分别生成 | 在颜色事实中填写多个值，用逗号、顿号或换行分隔 |
| 每尺寸 | 按尺寸分别生成 | 填写尺寸或尺寸列表 |
| 每站点 | 按目标站点/语言分别生成 | 适合站点布景或站点差异方案 |
| 指定组合 | 按手动输入的组合生成 | 逐项输入后按回车，例如“米白-120×180” |

预计数量会按“方案数量 × 变体数 × 站点数”计算；营销图还会乘以目标语言数量。详情页每个方案都会显示预计成品张数。细节选择“实拍原图排版”时，每个变体最多使用 1 张主图，且不调用生图模型。

如果选择“每颜色”或“每尺寸”后仍只显示 1 个变体，先回到产品事实检查颜色/花色或尺寸列表是否已填写并保存。

## 五、生成、审核和导出

每个 SKU 按以下流程独立推进：

1. **白底处理**：点击“到工作台处理白底图”，完成后返回任务并批准白底图。
2. **生成内容**：点击“运行到下一阶段”，生成所选场景、材质、用途或细节白底图。
3. **内容审核**：检查商品结构、纹理、背面、尺寸和场景是否与实拍及类目规则一致；营销图开启时，先生成/刷新中文模板预览，再批准图片、文案与方案。
4. **本地化出图**：按所选语言和站点设置生成成图。
5. **合规检查**：运行检查，处理阻断项后再导出。
6. **导出 ZIP**：所有 SKU 都显示“可导出”后，点击任务顶部“导出 ZIP”。

可以点击“全部运行到下一审核点”批量推进可处理的 SKU。每个 SKU 的审核点仍需人工确认；某个 SKU 失败不会替其他 SKU 自动跳过缺图或审核。

任务详情会保留规则版本和图片来源。修改类目、方案、变体、事实或细节实拍后，受影响的生成结果和审核会失效，需要重新生成；未受影响的结果可以继续复用。

## 六、常见问题

**创建任务按钮不可用**：等待规则、品牌和个人配置同步完成；如果规则读取失败，进入“规则与品牌”重试。

**提示缺少商品 Excel**：确认上传了 `.xlsx`，或 ZIP 内确实只有一个商品 Excel；纯图片 ZIP 不能单独创建批量任务。

**SKU 显示缺图**：检查 ZIP 文件夹名是否与 SKU 编号完全一致、图片是否命名为 `01`–`06`，或确认图片 URL 可以从服务器读取。

**细节方案没有可选图片**：先在当前 SKU 上传图片，再给图片标记正确用途；背面方案只能选择标记为“背面”的素材。

**不同颜色用了同一张细节图**：只有勾选“所有变体通用”才允许跨变体复用；否则请分别上传并填写变体名称。

**修改方案后不能直接导出**：重新生成受影响的图片、刷新中文预览并完成内容审核和合规检查，再导出。

**同一批 SKU 的进度不同**：这是正常情况。每个 SKU 有独立的白底、内容审核、合规和导出状态，可以先处理已准备好的 SKU。

## 七、推荐操作顺序

批量任务建议按以下顺序操作：

1. 先检查 Excel 中的 SKU、类目、颜色和尺寸字段。
2. 上传 ZIP 并确认任务详情中每个 SKU 都有主图。
3. 逐个 SKU 选择大类/子类，核对规则和示例图。
4. 先上传所有需要的背面、材质、包边和配件实拍，再绑定细节方案。
5. 选择变体范围并检查预计出图数量。
6. 批量运行到审核点，逐个审核白底、内容和合规结果。
7. 确认全部 SKU 可导出后再下载 ZIP，并保留任务规则版本和清单记录。
