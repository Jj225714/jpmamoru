# 场景图白条修复

原处理将横图或竖图完整缩放到白色正方形画布中，因此会产生上下或左右白条。

现在场景、材质、用途、营销底图及对比来源必须为真正的方图。图片模型返回非方图时，使用该结果和原商品参考做一次背景扩展，请求保留完整商品、不拉伸、不裁切。若仍不是方图，任务报错，不以补白兜底。额外修正不循环重试，会产生一次额外图片模型请求。

输出归一化还会用图片解码后的真实宽高复检，而非仅相信返回元数据。白底主图和白底特写仍允许等比居中留白。营销文字安全区继续使用原版式的位置，但要求连续的低纹理环境背景，不使用纯白横条或空栏。

已有文件不自动修改或扣费重跑。在明确执行内容重新生成时，旧版场景不再作为满幅场景缓存复用。纯尺寸检查无法判别模型直接画在方图内部的白条；生成提示词已禁止此行为，实际结果仍需人工验图。

实现：`scene-framing.ts`、`pipeline.ts`、`template-renderer.ts`。测试覆盖横竖图、一次修正、失败及过期结果、白底豁免和解码宽高复检；没有调用付费模型验证。
