# 跨境生图：维护类目规则与细节素材

## 修改或增加类目

在顶部「配置 → 跨境类目规则」直接通过网页表单操作，也可从「跨境生图 → 规则设置 → 平台类目管理」进入同一编辑器。日常维护不需要 Excel、脚本或第三方文件处理。全平台编辑和发布需要服务器授予规则管理员权限；浏览器本地 PIN 不能授予此权限。授权、部署和回滚见 [规则管理服务说明](commerce-policy-admin.md)。

1. 从当前版本创建草稿，在类目树中新增大类或子类，或选择已有类目编辑。可复制当前类目（含独立方案副本）后修改，也可调整没有下级的类目的所属大类；改父级后必须重新检查继承要求。支持两级结构。名称和导入别名必须全局唯一，以免商品被分配到错误类目。
2. 填写要求、适用图片类型、人物设置和默认拍摄设置，并绑定推荐方案和示例图。可以复制已有类目的方案后修改；普通新类目不需要改代码。
3. 查看「最终生效要求」。子类继承大类硬性要求，可增加限制；子类默认拍摄设置覆盖大类默认值，子类示例优先使用，没有时继承大类示例。修改大类会同时影响其子类在新版本中的要求。
4. 保存草稿、校验并发布。草稿可暂时不完整；发布时启用类目必须有可用方案，场景方案必须有示例，细节方案必须指定素材用途。有人物要求的规则只能应用于场景或用途图。

任务中的类目作图方案可以不配置；没有类目方案选择时不会阻断生图。已选择的方案仍会按当前类目规则执行，未选择时仅提示建议选择以获得更贴合类目的画面。

人物设置对所有方案开放：无人、成人手部／局部、成人半身、成人全身和自动均可选择。用户在方案中的选择优先于类目人物建议；生图只提示人物不得遮挡商品关键结构，细节与背面仍以绑定实拍为主体，前后对比保持人物、机位和光线一致。

已有类目采用「停用」，不要删除或复用 ID。两人同时编辑时，后保存的一方会收到版本冲突提示，应刷新后重新合并修改。规则版本和发布过的示例不可原地覆盖；回滚会以旧内容建立一个新版本。

初始类目包含地毯、地垫、桌垫及对应 10 个子类，另保留洞洞板和收纳筐。原表要求和单元格位置可在来源信息中核对。示例只指导空间和摆放，不决定商品花色，也不能提供商品性能证明。

## 上传和绑定背面、纹理等素材

1. 选择商品的大类和细类。有子类的大类必须明确选择细类；导入时可使用「细分类目」列填写名称或已设置的别名。
2. 在商品「细节素材」区上传实拍，或复用已有真实商品照片。标记正面纹理、背面、包边、侧面、配件等用途，并填写颜色／尺寸变体。只有明确通用的照片才标记为跨变体通用。
3. 在对应细节方案中选择照片和主参考图。正面纹理与背面应使用不同方案；背面方案需要真实背面照片，不能直接用正面白底图。
4. 选择「保真优化」或「原图排版」。保真优化调用模型调整光线、背景与构图，仍需人工核验；原图排版不调用生图模型，每方案每变体输出一张，保留实拍展示部位。

生成前会统一检查启用方案的素材绑定、可读取性、图片解码、变体和模型输入数量。缺图时补充素材或关闭对应方案后继续，不会静默回退到白底图。图中可见纹理不能自动变成“防滑”“耐热”等未经核实的宣传结论。

## 更新后的任务行为

新任务锁定创建时的已发布规则。修改规则并发布后，已有任务仍使用原版本；通过「使用新版方案创建副本」采用新版，历史结果继续可查看、导出。

替换背面实拍后，需要重新生成并审核依赖它的细节图及营销排版；无关场景与白底可继续复用。切换类目会使受影响内容和审批过期。生成中修改素材或类目，旧请求的结果不会覆盖新状态。

维护者可用 `deploy/prepare-category-catalog.mts` 从公共规则 JSON 和原始 XLSX 准备初始草稿。该脚本只输出草稿及图片摘要，不发布；实际发布必须走规则管理服务。
