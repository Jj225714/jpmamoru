# 商品信息建议与推荐方案 v3

## 使用入口

新建跨境任务的单商品表单、已有任务的 SKU 详情均提供“AI识别商品并建议卖点”。上传图片不会自动识别，点击才调用已配置的识图文本模型；不会自动生成图片。

识别读取真实主图、辅助实拍与已有资料，返回名称、受众、卖点、材质、使用方式、英文多级类目六项草稿。默认仅选空白字段；勾选允许替换后才能覆盖已有内容。待确认信息独立显示，不作为已证实卖点采用，也不会自动勾选产品事实确认。英文类目写入 `categoryPath`，不能替换用于选择方案的内部类目。

商品信息或图片改变后，旧建议不可采用；关闭表单或切换输入时迟到的响应不写回。建议草稿与已采用资料分开：草稿不清理结果，采用影响画面的内容才撤销相关结果及审核。商品 Excel 可没有卖点列，兼容原“产品描述/卖点(必填)”列名。

## 推荐方案与拍摄设置

四类各8项，共32项：空间主视觉、可见细节、日常用途、卖点展示默认开启；第二场景、成人互动、光影展示、使用前后按需选择。每项默认1张，仍可设0–4张。默认共享站点且营销开启时，最终张数为白底1张、无文字3张及每语言1张营销图，即 `4 + L`；营销关闭为4张。

场景、光影、目标受众、人物出镜及景别采用系统默认 → 方案推荐 → 品牌/任务拍摄设置 → 单项设置。未设值表示继承，不会把所有设置自动做排列组合。人物方案默认成人局部；细节和前后对比固定无人。Shopee/TikTok的表现方式是创作建议，不是平台认证规则；共享场景不自动套用国家人物面孔、族裔或宗教身份。

高级精确尺寸、安装、FAQ及性能要求不进入默认推荐，可在规则编辑器中“新增高级方案”，默认关闭，保留事实和校对门槛。旧40条规则及参考图保留在历史版本，不强行转换旧任务选择。

## 前后对比与审核

前图先生成，后图携带实际前图与商品参考锁定机位、光线及空间。两幅来源以 `comparison-source` 保存，并用实际前图内容身份约束后图重用。失败重试保留已成功前图；前图改变则后图必须重做。中间来源不计成品数量，中文预览和最终营销图引用有序来源对。

画布中两幅方形图独立、完整并排，标签、文字和品牌覆盖可编辑。来源图层须保持可见、不透明度至少95%、无旋转、不重叠且完整位于画板内，各边至少为画板对应边的20%。提交、审核及导出均检查这些条件，避免隐藏前图后仍通过对比图审核。来源位图不能被直接替换后冒用原生成记录。

人工合规确认须指向仍存在的当前检查项，v3检查结果绑定素材修订；旧按钮或失效检查ID不能把未完成任务标为可导出。

## 维护与兼容

- `creative-presets.ts` 定义32项；`creative-brief.ts` 负责继承与提示词编译。
- `product-suggestions.ts` 负责草稿解析、输入身份和采用保护；`product-base-prompt.ts` 保留原工作台接口，另提供跨境结构化接口。
- 新任务 `visualPipelineVersion: 3`；旧任务通过“使用新版方案创建副本”获得新方案。原任务完整保留，合格白底可复制到待审核状态，不自动付费运行。
- 持久化版本4只补充可选字段，不强制升级任务。没有服务器目录的本地环境在创建新任务时建立推荐规则副本。
- 新服务器目录为 `/public-rules/catalog-creative-v1.json`，运行时键为 `commerceCreativePolicyCatalogUrl`。旧v3/v4目录分别留给旧客户端；公共目录绝不包含私人任务、图片或模型密钥。

## 验证边界

自动化测试覆盖配方、参数继承、建议采用、取消与失效、成对生成、画布及导出。浏览器模拟识图验证首次点击、上传缓存、已有内容保护及关闭后迟到响应，不调用真实模型。真实材质、用途、人物动作和前后场景一致性仍需实图验收，不能由测试数量保证。
